Proof for the track judges, saved as it happens (010 Behavior 6 and PL-10). One file per item: `YYYY-MM-DD-HHMM-<tool>-<what>.png` plus a `.md` with one paragraph: what happened, what the tool found, the root cause, and the PR that fixed it.

- Radar: AI investigation of a real issue on our cluster
- Dash0: Agent0 or MCP finding, the "Conquest live" dashboard, the XP SLO
- Gitar: a review on one of our PRs, a CI failure it diagnosed and auto-fixed
- Elasticsearch: a rank request and its query (Kibana or Dev Tools screenshot)

Never stage or fake an incident.
