# Build

The checklist. Each step names the spec and criteria it builds. Take the first unticked step that isn't claimed, put your name on it, then build it on your own branch.

## Rules

1. One step at a time. Read every spec the step names.
2. Tests are named by criterion ID (`it("XX-1 ...")`).
3. Done = tests pass, box ticked, log line added below, committed with the step and IDs in the message.
4. Ambiguity goes in `DECISIONS.md`, then keep going.
