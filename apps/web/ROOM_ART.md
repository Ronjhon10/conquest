# Room art v1

Generated with the built-in imagegen tool using `public/characters/wizard-v1.png` as a style reference. Original transparent PNGs are copied unchanged into `public/rooms/keynote-v1.png` and `public/rooms/workshop-v1.png`. These are decorative illustrative boss-room archetypes, not portraits of actual speakers or real venue floor plans. The talk, speaker names, and physical room labels come from the APIs. Next Image serves sized versions; list view omits artwork entirely. Stable chronological stop numbers select alternating art and survive step-free filtering.

## Keynote prompt

Use case: stylized-concept. Asset type: production game map room illustration with true transparent background. Input image is STYLE REFERENCE ONLY: match this character's detailed 16-bit anime-inspired pixel-art craft, crisp square stepped outlines, layered charcoal/slate/cream materials, warm restrained gold and blue accents, three-tone shading. Create ONE isometric cutaway conference boss room, isolated diorama on alpha transparency. A contemporary conference auditorium reimagined as a dungeon chamber: chunky charcoal stone foundations, cream brick back walls, open front, small raised stage, glowing blue presentation screen with abstract geometric shapes (NO text), two banks of compact seats, warm wall lanterns, doorway at front edge. One friendly but imposing conference-speaker boss stands clearly on the central stage: detailed dark-haired adult in charcoal technical coat, conference lanyard, expressive face and boots, a little larger than normal attendee scale. Room should have the same amount of crafted detail as the reference character, NOT simple vector art, NOT blurry painted art. Three-quarter overhead isometric camera, fully visible floating room platform, generously framed with transparent padding, centered square composition. Make scene readable at 320 CSS pixels. No text, lettering, labels, UI, frames, watermarks, outer backdrop or separate cast shadow. Preserve real alpha transparency outside the room. This is a new companion environment asset, do not reproduce the reference character as a standalone portrait.
